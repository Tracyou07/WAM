# Round02 variational sharing v0.2

This extension implements frozen contract SHA256
`cb2f30413d8eedd9f307445ae603b4dbf0dffae4275957b39eb877af7ef6d64f`.
Use the native legacy-prefix, decoupled-same-step/video-only program and strict
batching. Action and world objectives retain native coefficients of one.

## Assembly order

1. Construct `VisualTower` with the target backbone, action and state dimensions.
2. Call `load_public_video_checkpoint_into_tower` from
   `open_wam.models.visual_tower.public_pretraining` on the real CPU tower, with
   the pinned public checkpoint SHA256. Required video/frontend tensors must
   match exactly. Serialized dummy action/state tensors are ignored and listed
   in the returned report; native auxiliary initialization is retained.
   Source auxiliary keys are the exact 23 names in the pinned public format;
   missing/unknown source auxiliaries are rejected. Native target conditioning
   keys have their own explicit initialization schema.
3. Call `build_variant_pipeline_from_config(config, visual_tower=tower)`.
   Set `load_reference_core_weights=False` to avoid a second weight source.
   Native action initialization runs before ownership transfer. Interpolation
   from video weights provides an initialization, not a trained action policy.
4. Call `configure_variational_sharing` from
   `open_wam.models.policy_variants.dual_expert.variational_sharing` with
   `arm=...`, `expected_layers=30` and an explicit `route_seed`.
5. Construct the optimizer and distributed wrappers after these steps.

The four arm strings are `native_joint`,
`same_capacity_deterministic_kv_blend`, `variational_sharing`, and
`forced_private_world_gradient_off`. Only final paired block video K/V is
trainable on the world side. Private K/V is initialized from those projections
with distinct Parameter identities and storage; upstream action gradients
remain connected through video hidden states.

## Native callers and state

Training uses ordinary `pipeline.forward_train_from_latents`. Supply genuinely
observed `batch.extra['condition_latents']` and native frame-aligned proprio
inputs. The prior reads only the explicit observed prefix. Both action routes
reach native post-DiT decoding; the weighted evidence uses only noisy-action
targets. World prediction/loss runs once. The neutral evidence owner is
`models/common/route_evidence.py`.

Inference uses ordinary `pipeline.forward_infer_step_from_latents`. The prior
reads the latest real observation and the controller samples one route before
the whole chunk ODE. Optional `PolicyInferContext.initial_route_uniform`
supports paired controls. CFG and private projection caches retain that route
throughout the chunk. Private K/V caches are generated by the private modules.

The controller stores route RNG and current route as Tensor buffers with custom
state-dict save/load hooks. All model state entries remain Tensor-only. A runner
must also save optimizer, scheduler, data/sampler position and action/noise RNG.
The synthetic CPU resume test does not establish real sampler or FSDP resume.

## Verified scope

CPU checks cover four native arms, loss/gradient equivalence at initialization,
world/private gradient isolation, observed-prefix invariance, chunk routing,
private cache, activation checkpointing, BF16 autocast and ordinary AdamW resume.
Actual public weights also pass 30-layer CPU load/warm-start/attach ownership
audit at video width 3072 and action width 2048. Full-width forward/backward,
real-data training, CUDA kernels, FSDP and task performance require separate
acceptance. Sequence-packed/padded routing currently rejects execution because
its route index mapping has not been implemented.

## Preprocessing component paths and LIBERO views

The LIBERO condition augmentation caller applies the same
`fit_frames(..., 128, 128, 'letterbox_pad')` transform as the base encoder to
each raw camera before building the 128x256 RGB canvas. Agent occupies the left
slot and wrist the right. Native placement produces 48x8x16 combined latent
geometry; this change does not alter source-frame selection. Generic frame
conversion without an explicit target retains its original size.

Prompt-cache fingerprints resolve `text_encoder_subdir` and `tokenizer_subdir`
against `pretrained_model_name_or_path` with the same component-path resolver
as the native loader. Absolute component paths stay direct; semantic fingerprint
keys remain `text_encoder/<file>` and `tokenizer/<file>` for legacy compatibility.
Prompt encoding still requires a valid resolved experiment config. The example
pretraining YAML with empty `video_sources` is a generation template.
